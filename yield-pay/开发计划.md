> 以收益抵费 — 让 Gas Fee 消失在未来的收益里

**项目方:** LI.FI Hackathon
**创建日期:** 2026-04-11
**状态:** 规划完成，待启动

## 一、项目愿景

"让 Gas Fee 消失在未来的收益里。"

在 Web3 世界，手续费（Gas Fee）是用户跨入 DeFi 门槛的最大心理障碍。Yield-Pay 重新定义了支付逻辑：它不是让用户"现在"掏钱，而是通过 LI.FI API 将资产存入高收益池，并利用预期的未来利息来对冲本次操作的成本。我们的目标是让用户感知到：这是一次"免费"甚至是"自带盈利"的跨链操作。

### 核心解决痛点

| 痛点 | 解决方案 |
|------|----------|
| 支付阵痛感：传统 DeFi 存款在开始赚钱前必须先扣款 | 显示回本倒计时，而非即时扣款 |
| 复杂的成本核算：用户难以计算回本时间 | 自动计算并展示回本周期 |
| 操作阻力：用户因手续费放弃高收益机会 | 突出"零成本"体验和快速回本 Vault |

## 四、API 集成

### 4.1 LI.FI API 端点

#### 获取 Quote (费用报价)
```
GET https://li.quest/v1/quote
```

| 参数 | 类型 | 描述 |
|------|------|------|
| fromChain | integer | 源链 ID |
| toChain | integer | 目标链 ID |
| fromToken | string | 源 Token 地址 |
| toToken | string | 目标 Vault Token 地址 |
| fromAddress | string | 用户钱包地址 |
| toAddress | string | 接收地址 |
| fromAmount | string | 金额 (最小单位) |

**响应中的关键数据:**
- `action.gasCosts` — Gas 费用
- `action.feeCosts` — 协议费用
- `action.toAmount` — 预计收到的 Vault Token 数量

#### 执行交易
```
POST https://li.quest/v1/quote
```

或使用 SDK:
```typescript
import { createConfig, getQuote, executeRoute, convertQuoteToRoute } from '@lifi/sdk';

const route = convertQuoteToRoute(quote);
const result = await executeRoute(route, {
  updateRouteHook: (updatedRoute) => {
    console.log(`Status: ${updatedRoute.steps[0].execution?.status}`);
  },
});
```

## 五、核心计算逻辑

### 5.1 回本周期计算

```typescript
interface CostBreakdown {
  bridgeFee: number;      // USD
  gasCost: number;         // USD
  swapFee: number;         // USD
  totalCost: number;       // USD
}

interface YieldProjection {
  apy: number;             // e.g., 0.152 (15.2%)
  dailyYield: number;      // 本金 * APY / 365
  breakEvenDays: number;   // totalCost / dailyYield
}

function calculateBreakEven(
  costs: CostBreakdown,
  amountUSD: number,
  apy: number
): YieldProjection {
  const dailyYield = (amountUSD * apy) / 365;
  const breakEvenDays = costs.totalCost / dailyYield;

  return {
    apy,
    dailyYield,
    breakEvenDays: Math.ceil(breakEvenDays * 10) / 10, // 保留一位小数
  };
}
```

### 5.2 成本汇总

```typescript
function aggregateCosts(quote: QuoteResponse): CostBreakdown {
  const gasCosts = quote.action?.estimate?.gasCosts ?? [];
  const feeCosts = quote.action?.estimate?.feeCosts ?? [];

  const totalGasUSD = gasCosts.reduce((sum, g) => sum + parseFloat(g.amountUSD || '0'), 0);
  const totalFeeUSD = feeCosts.reduce((sum, f) => sum + parseFloat(f.amountUSD || '0'), 0);

  return {
    bridgeFee: totalFeeUSD,
    gasCost: totalGasUSD,
    swapFee: 0, // 从 feeCosts 中细分
    totalCost: totalGasUSD + totalFeeUSD,
  };
}
```
